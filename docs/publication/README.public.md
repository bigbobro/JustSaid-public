# JustSaid

JustSaid — local-first meeting transcription and notes for macOS

JustSaid 是一个 macOS 应用，负责把一场会议**记全、理清、带走**：会中实时转写、随会议推进的整理与待办提炼，会后生成纪要与行动清单。录音、转写和纪要都保存在你自己的 Mac 上；云端能力只在你配置了自己的服务后才会启用。

## 它能做什么

- **会议提醒。** 会议软件开始通话时提醒你开始记录，通话结束后提醒你结束。由提醒开始的记录默认只录该会议软件的声音（浏览器会议录整个浏览器），录制失败时改录全部系统声音并提示；手动开始仍录全部系统声音。
- **会中实时转写。** 麦克风与系统声音两路同时采集，用本机运行的 Qwen3-ASR 模型逐句转写，不上传会中音频。转写可以收起成底部一行预览，也可以展开成快速面板或固定到左侧边看边记。
- **整理区随会议推进。** 已经沉淀的讨论按话题整理成活文档，修订留痕；「当前正在聊」一眼看到正在讨论什么，「章节」可以回到任一话题。内容适合时，话题会配一张图，按内容选用步骤、表格、时间线、层级树、关键数字、因果链或流程图。
- **替你记 · 承诺与待办。** 会中说到的承诺和待办会被单独记下，标出归属和时限；带时间锚点的记录可点旁边的定位按钮跳回转写位置。
- **补充记录与标记重点。** 转写之外，你可以随手补一句，或用快捷键给当前时刻打标记。
- **闲聊不进纪要。** 录制中点工具栏的「闲聊」或按 `⌥⌘X` 开始，再按一次结束。这段照常录音和转写，只是不进纪要。会后也可以在「完整转写」里把一段或连续几段设为「不进纪要」，重新生成纪要时生效。
- **会后精转与纪要。** 结束会议后，整场录音可以交给你自己申请的云端识别服务重新转写，再生成纪要和行动清单，与人工笔记一起存进会议库。
- **认名。** 精转完成后，应用用「会中总结」配置的模型从对话里找出谁是谁（比如自我介绍、被人叫到名字），在「完整转写」里给出认名建议，附上原话作证据，点一下可跳回那句话。你点「采纳」才会改名；改好名字后重新生成纪要，纪要里就会用上这些名字。
- **会议页三个页签。** 「这场会」可以在「结构」和「正式纪要」之间切换：结构依次是结论带、会议骨架（可含图表）、替你记，以及「遗留的活」里等确认和尚有分歧的事。「完整转写」用来核对发言人、决定哪些内容不进纪要。「会中记录」保留会中整理区的留痕，旁边是你的补充记录。
- **会议库。** 所有会议按时间排列，支持全文搜索、按客户与项目归类、导出会议包。
- **导入录音。** 已有的音频或视频文件（mp3、m4a、wav 等）可以拖到首页的「导入录音」框，或在会议库点「导入录音」。导入后直接走会后精转并生成纪要，所以要先配好会后精转；导入的会议没有会中实时转写和整理区。
- **我的待办。** 集中管理要跟进的事：可以手工新增，也可以在会议页右栏的「待办候选」里核对后加入。按智能视图（今天、逾期、待补全等）或客户、项目查看，可在列表和四象限之间切换，拖到别的象限后会先让你确认要改的字段。移除的待办进回收箱，可以恢复，也可以确认后永久清空。
- **词典与收割箱。** 「词典」页维护常用专名和它们的不同叫法，用于精转与纪要。生成纪要时发现的新专名先放进「收割箱」，由你决定并入已有词条、新建词条或忽略，不会自动写进词典。

## 下载与安装

**系统要求：** Apple Silicon 的 Mac，macOS 15 或更高版本。

1. 到本仓库的 [Releases](https://github.com/bigbobro/JustSaid-public/releases) 页面下载最新的 `JustSaid-<版本>-b<构建号>-arm64.dmg`，以及同一页上的 `.dmg.sha256` 与 `VERSION.txt`。
2. 在 DMG 所在目录打开「终端」，核对下载文件没有损坏或被替换：

   ```sh
   shasum -a 256 JustSaid-*.dmg
   ```

   输出的 64 位字符串应与 `.dmg.sha256` 文件里的完全一致。
3. 打开 DMG，把 `JustSaid.app` 拖到旁边的 `Applications`，然后推出 DMG。
4. 这个应用由作者自签名，没有经过 Apple 公证。第一次打开时 macOS 会拦下它：先在「应用程序」里双击一次让系统弹出提示并点「完成」，再到「系统设置 → 隐私与安全性」的「安全性」一栏找到 JustSaid，点「仍要打开」。不需要关闭 Gatekeeper，也不需要执行任何命令。
5. 第一次录制时按系统提示允许麦克风与「屏幕与系统音频录制」。

DMG 根目录的 `VERSION.txt` 写着这个包对应的源码提交；到本仓库对应版本的 tag 里打开 `PUBLIC_EXPORT_MANIFEST.json`，其中 `source_sha` 应与它一致。三处都对上，说明你拿到的包出自这里公开的源码。

首次启动时，应用会提示下载默认的本地识别模型（Qwen3-ASR 与 Silero VAD）；只有你点了「下载并安装」才会联网获取。

## 应用更新

在 JustSaid 菜单中选择「检查更新…」；「设置 → 通用 → 应用更新」可开关自动检查。发现新版后仍由你选择安装。下载准备好时，选「立即安装并重启」会重新打开新版；选「稍后」会在下次主动退出 App 时安装，并保持关闭。关闭主窗口会继续后台运行，不等于退出。

录制、会后处理、导入或模型准备中，更新器会提示完成后重试。如果此前已经选择立即安装并重启、随后被忙碌保护挡住，更新仍保留安装与重启选择，下次退出时可能完成它。

1.0.3 及更早版本需要先手动安装一次含更新器的版本。检查更新只请求公开清单与安装包，不发送会议内容或系统画像。下载或验证失败时可稍后重试；仍可从 Releases 手动取得安装包。手动下载不需要另外安装 `appcast.xml`。

## 首次配置

应用不预置任何云端账号或密钥。会中实时转写只用本地模型，装好就能用；会后精转、会中总结与会后纪要需要你自己的服务，在「设置」（`⌘,`）的「模型与服务」里分五个角色配置：

| 角色 | 需要准备什么 |
| --- | --- |
| 会中速记 | 不需要，默认使用本地 Qwen3-ASR |
| 会后精转 | 火山引擎「豆包录音文件识别」的凭证，以及一个你自己的 Cloudflare R2 存储桶用于临时中转音频 |
| 会中快总结 | OpenAI 兼容的对话模型服务（Base URL、模型名、API Key），或用自己的 ChatGPT 订阅登录 |
| 会中慢总结 | 同上，可以与快总结使用同一渠道，也可以分别选择渠道、模型和推理档位 |
| 会后纪要 | 同上，与会中两路分别选择渠道、模型和推理档位 |

使用 ChatGPT 订阅时，点「新建渠道」，供应商选「ChatGPT 计划用量」，创建后点「Continue with ChatGPT」在浏览器登录，再为各角色选择账户可用的模型与推理档位。总结和纪要计入你的 ChatGPT 计划用量；会后精转仍使用单独配置的识别服务。

豆包录音文件识别与 Cloudflare R2 的申请步骤，随包附在 DMG 根目录的 `docs/` 文件夹里：

- `docs/豆包录音文件识别-申请教程.md`
- `docs/Cloudflare-R2-申请教程.md`

密钥只保存在你这台 Mac 的钥匙串里。建议给凭证只授予本应用需要的最小权限，不要使用管理员级密钥。

## 点名提醒与悬浮显示

在「设置 → 点名提醒」添加名字或昵称并开启提醒，只在 JustSaid 正在录制会议时生效。它复用本机实时转写，不需要另装识别模型；识别有延迟，也可能漏认名字。

「悬浮显示」可选侧边吸附、悬浮小窗或关闭。吸附把手可拖到四边，点击展开会议内容，选「保持展开」可转为小窗。静默高亮在当前显示中提醒；独立强提醒会单独显示名字与「知道了」，即使关闭了悬浮显示也可使用。切回主窗后，提醒会在主窗内接续。

会中左侧栏的「点名」按钮可以暂停或恢复提醒。暂停时不弹出、不发声，恢复后不会重放暂停期间已识别的点名；新到达的识别仍可能来自几秒前的说话。小窗 × 只关闭悬浮显示，点「知道了」才确认当前提醒。

## 数据与隐私

- 会议的录音、转写、纪要和笔记都写在本机 `~/JustSaid/meetings` 目录下，按会议分文件夹保存，可以直接备份或删除。
- 会中实时转写完全在本机完成，不上传音频。
- ChatGPT 渠道的登录凭证保存在这台 Mac 的钥匙串中，与 API Key 分开存放。
- 由提醒开始的记录默认只采集该会议软件的系统声音，浏览器会议会采集整个浏览器；按 App 采集失败时会改为采集全部系统声音并提示。麦克风仍正常采集，手动开始仍采集全部系统声音。
- 会中转写和会后精转前的回声消除都在本机完成，原始录音保留。
- 只有你在设置里配置过的服务会被调用：会后精转会把该场录音临时上传到你自己的 R2 存储桶并交给识别服务读取，识别完成后删除中转对象（删除失败会在会后处理里提示）；会中总结与会后纪要会把转写文本发给你配置的模型服务。这些数据的保留规则以你所选服务商与账号设置为准。
- 本仓库不包含任何会议数据、录音或个人信息。

## 从源码构建

本仓库使用 Swift Package Manager，保留了原仓库的 Swift 语言模式，以及固定版本的 sherpa-onnx、Sparkle 与 WebRTC Audio Processing 依赖。在 Apple Silicon、macOS 15 及以上、安装了 Xcode 命令行工具的机器上：

```sh
swift package resolve
swift build --build-system native --product JustSaid
```

构建产物是一个未打包的可执行文件；Releases 页上的 DMG 才是打包并签名后的版本。

SwiftPM 会从独立的 `deps-webrtc-apm-2.1` Release 下载约 1.25 MB 的 arm64 静态 XCFramework，并校验清单中锁定的 SHA-256。这是依赖资产；下载 App 时仍选 App 版本的 DMG。第三方源码和依赖构建脚本不包含在公开树中。

# JustSaid

JustSaid — local-first meeting transcription and notes for macOS

JustSaid 是一个 macOS 应用，负责把一场会议**记全、理清、带走**：会中实时转写、随会议推进的整理与待办提炼，会后生成纪要与一页纸。录音、转写和纪要都保存在你自己的 Mac 上；云端能力只在你配置了自己的服务后才会启用。

## 它能做什么

- **会中实时转写。** 麦克风与系统声音两路同时采集，用本机运行的 Qwen3-ASR 模型逐句转写，不上传会中音频。转写可以收起成底部一行预览，也可以展开成快速面板或固定到左侧边看边记。
- **整理区随会议推进。** 已经沉淀的讨论按话题整理成活文档，修订留痕；「当前正在聊」一眼看到正在讨论什么，「章节」可以回到任一话题。
- **替你记 · 承诺与待办。** 会中说到的承诺、待办和决定会被单独记下，标出归属和时限；带时间锚点的记录可点旁边的定位按钮跳回转写位置。
- **补充记录与标记重点。** 转写之外，你可以随手补一句，或用快捷键给当前时刻打标记。
- **会后精转与纪要。** 结束会议后，整场录音可以交给你自己申请的云端识别服务重新转写，再生成纪要、一页纸和行动清单，与人工笔记一起存进会议库。
- **会议库。** 所有会议按时间排列，支持全文搜索、按客户与项目归类、导出会议包。

## 下载与安装

**系统要求：** Apple Silicon 的 Mac，macOS 15 或更高版本。

1. 到本仓库的 [Releases](https://github.com/bigbobro/JustSaid-public/releases) 页面下载最新的 `JustSaid-<版本>-b<构建号>-arm64.dmg`，以及同一页上的 `.dmg.sha256` 与 `VERSION.txt`。
2. 在 DMG 所在目录打开「终端」，核对下载文件没有损坏或被替换：

   ```sh
   shasum -a 256 JustSaid-*.dmg
   ```

   输出的 64 位字符串应与 `.dmg.sha256` 文件里的完全一致。
3. 打开 DMG，把 `JustSaid.app` 拖到旁边的 `Applications`，然后推出 DMG。
4. 这个应用由作者自签名，没有经过 Apple 公证。第一次打开时 macOS 会拦下它：先在「应用程序」里双击一次让系统弹出提示并点「完成」，再到「系统设置 → 隐私与安全性」的「安全性」一栏找到 JustSaid，点「仍要打开」。不需要关闭 Gatekeeper，也不需要执行任何命令。
5. 第一次录制时按系统提示允许麦克风与「屏幕与系统音频录制」。

DMG 根目录的 `VERSION.txt` 写着这个包对应的源码提交；到本仓库对应版本的 tag 里打开 `PUBLIC_EXPORT_MANIFEST.json`，其中 `source_sha` 应与它一致。三处都对上，说明你拿到的包出自这里公开的源码。

首次启动时，应用会提示下载默认的本地识别模型（Qwen3-ASR 与 Silero VAD）；只有你点了「下载并安装」才会联网获取。

## 首次配置

应用不预置任何云端账号或密钥。会中实时转写只用本地模型，装好就能用；会后精转与会中总结需要你自己的服务，在「设置」（`⌘,`）里分四个角色填写：

| 角色 | 需要准备什么 |
| --- | --- |
| 会中速记 | 不需要，默认使用本地 Qwen3-ASR |
| 会后精转 | 火山引擎「豆包录音文件识别」的凭证，以及一个你自己的 Cloudflare R2 存储桶用于临时中转音频 |
| 会中总结 | 一个 OpenAI 兼容的对话模型服务（Base URL、模型名、API Key） |
| 会后纪要 | 同上，可以与会中总结相同或不同 |

豆包录音文件识别与 Cloudflare R2 的申请步骤，随包附在 DMG 根目录的 `docs/` 文件夹里：

- `docs/豆包录音文件识别-申请教程.md`
- `docs/Cloudflare-R2-申请教程.md`

密钥只保存在你这台 Mac 的钥匙串里。建议给凭证只授予本应用需要的最小权限，不要使用管理员级密钥。

## 数据与隐私

- 会议的录音、转写、纪要和笔记都写在本机 `~/JustSaid/meetings` 目录下，按会议分文件夹保存，可以直接备份或删除。
- 会中实时转写完全在本机完成，不上传音频。
- 只有你在设置里配置过的服务会被调用：会后精转会把该场录音临时上传到你自己的 R2 存储桶并交给识别服务读取，识别完成后删除中转对象（删除失败会在会后处理里提示）；会中总结与会后纪要会把转写文本发给你配置的模型服务。这些数据的保留规则以你所选服务商与账号设置为准。
- 本仓库不包含任何会议数据、录音或个人信息。

## 从源码构建

本仓库使用 Swift Package Manager，保留了原仓库的 Swift 语言模式与固定版本的 sherpa-onnx 依赖。在 macOS 15 及以上、安装了 Xcode 命令行工具的机器上：

```sh
swift package resolve
swift build --product JustSaid
```

构建产物是一个未打包的可执行文件；Releases 页上的 DMG 才是打包并签名后的版本。
